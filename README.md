# EcoGate – Smart Airport Gate Management Prototype

EcoGate is a fully‑client‑side web prototype that simulates an IoT‑enabled airport gate.  
It demonstrates sensor data simulation, decision logic for lighting, HVAC, ventilation, water management, and provides a sustainability score and recommendations.

## Features

- **Live sensor simulation** – occupancy, temperature, humidity, light, air quality, energy, water.
- **Decision engine** – automatic lighting, HVAC, ventilation, and water control logic.
- **Eco Score** – dynamic sustainability metric (0–100).
- **Smart recommendations** – actionable insights.
- **Actuator simulation** – visual representation of state changes.
- **Airport gate map** – click gates to view simulated sensor data.
- **Energy analytics** – current, daily, and saved energy with a simple chart.
- **Demo scenario** – step‑by‑step demonstration for presentations.
- **Alerts** – visual indicators for critical conditions.

## How to run the project

1. Clone or download the repository.  
2. Open the `ecogate` folder.  
3. Double‑click `index.html` or open it in your browser (Chrome/Firefox/Edge).  
4. The dashboard will load automatically – no server or build steps required.

## How to demonstrate it in 2 minutes

1. **Show the dashboard** – let the user see the live sensor cards.  
2. **Toggle auto‑simulation** – press the “Auto Simulation ON” button and watch values change every 3 s.  
3. **Press “Demo Scenario”** – the demo will switch from a normal to a busy gate in ~4 s, triggering HVAC, lighting, ventilation, and eco‑score updates.  
4. **Explain the decision logic** – point to the actuator cards and recommendation panel.  
5. **Highlight the alerts** – show how the system flags high occupancy or poor air quality.  
6. **Wrap up** – show the energy analytics chart and the “Before vs After” comparison.

## How the IoT concept works

1. **Sensors** – In a real deployment, temperature, humidity, light, occupancy, etc. would be measured by physical devices (e.g., DHT22, PIR, LDR).  
2. **Data Collection** – Sensors send data to an IoT gateway (e.g., ESP32).  
3. **Processing** – The gateway forwards data to a backend or cloud service where the EcoGate decision engine runs.  
4. **Actuators** – The engine sends commands to actuators (LEDs, HVAC controllers, valves) to adjust lighting, temperature, etc.  
5. **Dashboard** – The same backend serves a web UI (this prototype) to visualize sensor data, recommendations, and sustainability metrics.  

> **Note:** This prototype uses *simulated* sensor data generated by JavaScript. Replace the `generateSensors()` function with real sensor callbacks when integrating hardware.

## What to say if the panel asks “Where are your sensors?”

> "All sensor data is simulated by JavaScript running in the browser. In a production system, we would connect real IoT devices (e.g., ESP32, Arduino, Raspberry Pi) to measure temperature, humidity, occupancy, light, air quality, energy, and water consumption. These devices would send data to an IoT gateway that forwards it to the EcoGate backend, where the decision engine applies the same logic we demonstrate here."
