✈️ EcoGate — IoT-Based Smart Sustainable Airport Gate Management System

EcoGate is a software-based IoT simulation prototype. Sensor and actuator values are simulated for demonstration. In real-world deployment, these components can be connected using ESP32/Arduino, IoT gateways and cloud platforms.

Academic prototype · HTML + CSS + vanilla JavaScript · zero external libraries · works fully offline
